# Changelog

## 0.2.0

- The launcher checks for a new version when it opens (or from Check for Updates... in its menu) and updates with one click: it downloads the new Builder, which rebuilds the app from the game inside the current one and opens it.
- Repainting a car with the spray gun shows the new paint instead of the old picture.
- Quick clicks, such as a trackpad tap or two-finger tap, are no longer lost.
- A two-finger swipe on the trackpad rotates the view like a right-button drag.

## 0.1.0

- First release of Gearhead Garage Builder: makes Gearhead Garage.app on your Mac from your own copy of Snap-on Gearhead Garage (Build 131), from the CD image, the disc, GEAR.MSI or an installed game folder.
- The game runs as native ARM64 code with its full-color Direct3D mode drawn with Metal, the 256-color software mode, sound and music through CoreAudio, windowed or fullscreen.
